# Story 5.1 — Integração CIALA: Grau de Risco e Última Inspeção

## Status: Done

## Story

**Como** inspetor,  
**Quero** que o sistema consulte o CIALA automaticamente pelo IMO do navio,  
**Para que** o grau de risco e a data da última inspeção preencham a prioridade PSC no dashboard.

## Contexto

O CIALA (Acordo de Viña del Mar) é a base de dados PSC das Américas.
Com o IMO, consultamos o portal para obter:
- `risk_level`: grau de risco (high / standard / low)
- `last_inspection_date`: data da última inspeção PSC registrada

Esses dois campos alimentam `calculatePriority()`, que determina P1/P2/P3/N/A no dashboard.
