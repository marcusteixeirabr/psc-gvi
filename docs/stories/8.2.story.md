# Story 8.2 — Painel `/admin/health`: Status dos Scrapers

## Status: Done

## Story

**Como** administrador do sistema,  
**Quero** um painel em `/admin/health` que mostre o status atual de cada scraper,  
**Para que** eu possa identificar rapidamente se algum scraper está falhando sem precisar acessar os logs.

## Contexto

Com `scraper_runs` populada pela Story 8.1, este painel lê os dados e os apresenta de forma visual. É a ferramenta de diagnóstico diária de Marcus para garantir que a automação está funcionando.

**Acesso:** somente admin (mesmo grupo que delete/deactivate no `main.go`).

**Informações por scraper:**
- Status atual (🟢 ok / 🟡 parcial / 🔴 erro)
- Última execução: timestamp + duração
- Última mensagem de erro (se houver)
- Tendência: contagem de falhas nas últimas 10 execuções

## Acceptance Criteria

- [ ] AC1: Rota `GET /admin/health` acessível apenas para role `admin`
- [ ] AC2: Página exibe card para cada scraper (`zp21`, `auto_imo`, `auto_ciala`)
- [ ] AC3: Card mostra: status colorido, timestamp da última execução, duração, items processados/falhados
- [ ] AC4: Status visual: 🟢 `success` | 🟡 `partial` | 🔴 `error` | ⚪ nunca executou
- [ ] AC5: Seção "Histórico recente" com tabela das últimas 20 execuções de todos os scrapers, ordenadas por `started_at DESC`
- [ ] AC6: Link para `/admin/health` visível no nav principal somente para admins

- Formato de duração: `< 1s` | `2.3s` | `1m 5s` — converter `duration_ms` no template ou no handler
- Dependência: Story 8.1 deve estar concluída (tabela `scraper_runs` deve existir)
