# Story 9.3 — Busca Rápida Global: Nome ou IMO no Nav

## Status: Done

## Story

**Como** inspetor,  
**Quero** um campo de busca no menu de navegação que aceite nome ou IMO do navio,  
**Para que** eu possa chegar rapidamente ao cadastro de qualquer navio sem navegar pela lista completa.

## Contexto

Com navios recorrentes (mesmos navios voltam mensalmente), os inspetores frequentemente precisam acessar um navio específico. Digitar o nome ou IMO no nav e pressionar Enter deve levar direto ao navio (se único resultado) ou exibir a lista filtrada (se múltiplos).

**Comportamento:**
- 1 resultado → redireciona direto para `/vessels/:id`
- 0 ou 2+ resultados → exibe `/vessels?q=TERMO` com a lista filtrada

**Escopo da busca:** todos os navios acompanhados (campo `name` ILIKE e `imo` = exact match).

## Acceptance Criteria

- [ ] AC1: Campo de busca visível no nav principal (todos os usuários autenticados)
- [ ] AC2: Submit do campo (Enter ou botão) envia GET para `/vessels?q=TERMO`
- [ ] AC3: Com 1 resultado exato: redireciona para `/vessels/:id` diretamente
- [ ] AC4: Com 0 ou 2+ resultados: exibe lista filtrada com mensagem "X resultado(s) para TERMO"
- [ ] AC5: Busca por nome é case-insensitive e parcial (ILIKE `%termo%`)
- [ ] AC6: Busca por IMO é exata (se o termo parecer um IMO — 7 dígitos numéricos)
- [ ] AC7: Campo preserva o termo digitado após a busca (value="{{.Query}}")

## Notes

- `SearchVessels` query: `WHERE (name ILIKE $1 OR imo = $2) AND acompanhado = TRUE ORDER BY name LIMIT 20`
  - $1 = `%q%` (busca parcial por nome)
  - $2 = `q` (busca exata por IMO)
- Detecção de IMO: `len(q) == 7 && strings.TrimLeft(q, "0123456789") == ""`
- Redirect 1 resultado: `c.Redirect(http.StatusFound, fmt.Sprintf("/vessels/%d", results[0].ID))`
- Campo no nav: pequeno, `placeholder="Navio ou IMO"`, width ~160px — não ocupa muito espaço
- Compatível com Story 9.1/9.2: quando `?q` está presente, os outros filtros são ignorados (busca global tem prioridade)
