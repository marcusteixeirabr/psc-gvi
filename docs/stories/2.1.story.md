# Story 2.1 — Scraping ZP-21: Port Calls Automáticos

## Status: Done

## Story

**Como** editor ou admin,  
**Quero** disparar a busca na tabela de Manobras Previstas do ZP-21,  
**Para que** os port calls sejam criados automaticamente, sem digitação manual.

## Contexto

O ZP-21 (praticagem de Itajaí) publica em `ZP21_URL` uma tabela "Manobras Previstas"
com os navios previstos para o porto. Esta story implementa o scraper que lê essa tabela
e popula o banco com vessels e port_calls.

### Desafio: identificar o navio

O ZP-21 retorna apenas nome, LOA e Beam — sem IMO. O IMO só vem do equasys (Fase 4).

Regra de identificação:
1. Buscar no BD pelo **nome exato**
2. Se encontrado: verificar LOA e Beam com tolerância de **±5%**
   - Dentro da tolerância → **mesmo navio**
   - Fora da tolerância → **navio diferente com nome igual** (cria novo vessel)
3. Se não encontrado: **criar novo vessel** (category='estrangeiro', sem IMO)

### Desafio: entrada + saída = um port call

O ZP-21 pode listar o mesmo navio duas vezes no mesmo ciclo:
- Uma linha com manobra de **entrada** (previsão de atracação → ETA)
- Uma linha com manobra de **saída** (previsão de desatracação → ETD)

São o **mesmo port_call**. A lógica de merge:
- Se o vessel já tem um port_call com status `planned` ou `active` → atualizar esse registro
- Linha com entrada → atualiza `eta_date` / `eta_time`
- Linha com saída → atualiza `etd_date` / `etd_time`
- Se não existe port_call ativo → criar novo

### Trigger manual

O scraping é disparado manualmente por admin ou editor via `POST /scrape/zp21`.
Polling automático está previsto para uma story futura.

```go
type ManobrasRow struct {
    VesselName  string
    LOA         float64
    Beam        float64
    Terminal    string
    Date        string // formato raw do ZP-21, parsear para time.Time
    Time        string // pode ser "TBC" ou hora real
    ManeuverType string // "entrada" | "saída" (normalizar do texto original)
}
```

### Tolerância LOA/Beam

```go
func withinTolerance(a, b, pct float64) bool {
    if a == 0 || b == 0 {
        return true // sem dado → não descartar
    }
    return math.Abs(a-b)/a <= pct
}
```

Usar `pct = 0.05` (5%).

### Queries sqlc necessárias (port_call.sql)

- `GetVesselsByName` — retorna todos vessels com aquele nome (para comparar LOA/Beam em Go)
- `CreatePortCall` — cria novo port_call (zp21_sourced=true)
- `GetActivePortCallByVessel` — status IN ('planned','active') ORDER BY created_at DESC LIMIT 1
- `UpdatePortCallETA` — atualiza eta_date, eta_time, terminal
- `UpdatePortCallETD` — atualiza etd_date, etd_time
