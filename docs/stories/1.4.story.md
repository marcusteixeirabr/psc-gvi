# Story 1.4 — Vessel CRUD (sqlc + Gin + HTMX)

## Status: Done

## Story

**Como** editor ou admin,  
**Quero** cadastrar, visualizar e editar navios no sistema,  
**Para que** possamos manter o cadastro de embarcações que visitam o porto.

## Contexto

Esta story introduz o `sqlc` — a peça que conecta SQL ao Go sem ORM.

### Fluxo sqlc (aprenda este ciclo — você vai usá-lo para sempre)

```
1. Você escreve SQL em internal/db/query/vessel.sql
2. Roda: sqlc generate
3. sqlc lê as migrations (schema) + suas queries e gera Go typesafe
4. Você importa o pacote gerado (db/sqlc) nos seus handlers
```

Nenhum ORM. Nenhuma mágica. Você escreve SQL, Go escreve o boilerplate.

### CRUD de Vessel

| Rota | Método | Handler | Role |
|------|--------|---------|------|
| `/vessels` | GET | Lista todos | auth |
| `/vessels/new` | GET | Exibe formulário | editor, admin |
| `/vessels` | POST | Cria navio | editor, admin |
| `/vessels/:id` | GET | Detalhe do navio | auth |
| `/vessels/:id/edit` | GET | Formulário de edição | editor, admin |
| `/vessels/:id` | POST | Atualiza (forms não suportam PUT) | editor, admin |
| `/vessels/:id/deactivate` | POST | Soft delete | admin |

### O que o editor preenche no cadastro

`imo`, `name`, `flag`, `year_built`, `vessel_type`, `length_m`, `beam_m`

`risk_level` e `last_inspection_date` chegam via scraping do CIALA (Story 2.x).

## Dev Notes

### Conceito: por que sqlc em vez de ORM?

ORMs escondem o SQL. Parecem convenientes até você precisar de uma query complexa,
e então você luta contra o ORM em vez de escrever SQL diretamente.

sqlc te deixa escrever SQL puro (que você já sabe), e gera o código Go de integração.
O resultado é código previsível, rápido e 100% rastreável — você sempre sabe o SQL que roda.

### Conceito: soft delete

`active = false` em vez de `DELETE FROM vessels`. Por quê?
- Port calls históricos ainda referenciam o navio (FK com RESTRICT)
- Preserva histórico de inspeções
- Pode ser reativado se necessário

### Conceito: pgtype e nullables

Colunas SQL nullable viram ponteiros Go (`*string`, `*int32`, `*time.Time`).
`nil` em Go = `NULL` no banco. Você aprenderá a checar `if vessel.RiskLevel != nil`.
